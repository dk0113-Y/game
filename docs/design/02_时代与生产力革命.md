# 时代与生产力革命

## 已确定设计

时代不是单纯科技解锁，而是生产力革命后的玩法阶段切换。

生产力不是单一资源，而是综合指数，至少由以下方面构成：

- 食物剩余。
- 工具效率。
- 能源利用。
- 组织能力。
- 交通能力。
- 专业分工。

生产力革命应包含三类门槛：

- 生产力门槛：综合指数达到最低要求。
- 关键能力门槛：掌握能改变生产方式的关键能力，例如农业、畜力、冶金、航运、机械动力。
- 社会承载门槛：人口、组织、合法性、治理能力或阶层结构足以承受新生产方式。

时代切换后，旧机制应折叠为 Legacy / 遗产标签。旧机制可以继续影响新阶段，但不应要求玩家保持旧阶段微操粒度。

## 暂定设计

### 0. 流动采猎时代

- 核心玩法：小规模移动、探索地形、识别资源和生存机会。
- 主要资源：食物、知识、临时工具、路线记忆。
- 玩家操作对象：流动群体或核心家庭/氏族。
- 下一时代条件：稳定食物来源、可重复营地、基础工具和初步社会协作。

### 1. 营地与氏族时代

- 核心玩法：扎营、控制单格、开发周边潜力、形成早期权威。
- 主要资源：食物、木材、石料、知识、人口。
- 玩家操作对象：营地、氏族核心和开拓者。
- 下一时代条件：食物剩余、可持续采集/种植/畜养线索、营地人口稳定增长。

### 2. 村社农牧时代

- 核心玩法：固定聚落、农牧开发、人口增长、劳动组织。
- 主要资源：粮食、牲畜、木材、石料、工具。
- 玩家操作对象：村社、土地、劳动力分配和氏族权威。
- 下一时代条件：稳定剩余、专业分工、仓储、交通节点和早期等级结构。

### 3. 城镇与酋邦时代

- 核心玩法：多聚落整合、贡赋、工匠、宗教或仪式权威。
- 主要资源：贡赋、工艺品、威望、地方控制力。
- 玩家操作对象：酋邦中心、附属村社、精英集团。
- 下一时代条件：区域治理、军事组织、冶金或大型工程能力。

### 4. 国家与金属时代

- 核心玩法：法令、军队、行政、金属工具和武器、区域扩张。
- 主要资源：税赋、金属、粮仓、兵员、合法性。
- 玩家操作对象：早期国家、王室、官僚和军事核心。
- 下一时代条件：稳定财政、官僚体系、长距离交通、商业和农业剩余。

### 5. 农业帝国与商业时代

- 核心玩法：帝国治理、道路/水运网络、城市商业、阶层平衡。
- 主要资源：货币、税收、粮食、贸易品、行政能力。
- 玩家操作对象：王朝、帝国行政、商贸网络和地方精英。
- 下一时代条件：机械化前置能力、能源利用突破、资本和工场组织。

### 6. 工业时代

- 核心玩法：能源、工厂、铁路、城市化、劳资关系、国家能力。
- 主要资源：煤/油/电力、钢铁、资本、工人、科研能力。
- 玩家操作对象：工业国家、资本集团、政党或现代政权核心。
- 下一时代条件：信息网络、自动化、全球组织能力和知识生产体系。

### 7. 信息与星际时代

- 核心玩法：信息平台、自动化科研、行星级资源、星际基础设施。
- 主要资源：数据、算力、能源、稀有材料、组织信任。
- 玩家操作对象：国家、超国家组织、平台、技术官僚或星际政权核心。
- 下一阶段条件：暂未定义，可作为长期扩展目标。

## 当前实现状态

当前代码没有实现时代系统、生产力指数、生产力革命门槛或 Legacy 折叠。现有资源字段包括食物、木材、石料和知识，但它们尚未组合成生产力指数。

## 后续实现建议

- 第一版生产力指数可以先用少量字段计算，不要一开始就做复杂模型。
- 第一次生产力革命建议围绕“流动采猎 -> 营地与氏族”或“营地与氏族 -> 村社农牧”做垂直切片。
- 每次时代切换都应生成 Legacy 标签，记录旧阶段的优势、惯性和风险。
- 社会承载门槛不应只作为失败惩罚，也应提供改革、整合和妥协空间。

## 未决问题

- 当前原型应该从第 0 时代还是第 1 时代开始？
- 生产力指数是单一总分，还是由多个维度并列显示？
- 社会承载门槛失败时，是阻止时代切换，还是允许切换并触发危机？
- 信息与星际时代是否应拆分为两个独立时代？
