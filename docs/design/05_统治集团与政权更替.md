# 统治集团与政权更替

## 已确定设计

玩家不是抽象文明，而是统治集团、家族、王室、政权核心或后期组织。

科技和生产力革命会重新分配权力。文明进步不等于玩家统治受益。

核心系统链条为：

1. 科技 -> 改变生产方式。
2. 生产方式 -> 改变资源分配。
3. 资源分配 -> 改变阶层力量。
4. 阶层力量 -> 冲击统治结构。

每次生产力革命应触发 Regime Stress Test / 政权压力测试。

压力指标暂定包括：

- 合法性。
- 控制力。
- 精英整合。
- 财政汲取。
- 暴力垄断。

## 暂定设计

生产力革命可能带来的新权力集团包括：

- 土地长老。
- 祭司。
- 工匠。
- 官僚。
- 商人。
- 军官。
- 资本家。
- 工人。
- 技术官僚。
- 信息平台。

玩家应能通过多种策略应对：

- 吸纳：给予地位、职位、特权或政治参与。
- 垄断：将关键资源、技术或组织能力纳入统治核心。
- 压制：用军事、法律、税制或宣传限制新集团扩张。
- 放任：短期换取增长，长期承担权力外溢风险。
- 改革：调整制度，使新生产方式与统治结构重新匹配。

失败结果可以包括：

- 王朝更替。
- 政变。
- 内战。
- 被架空。
- 流亡。
- 分裂。

这些结果不必等同于文明灭亡。文明可能继续发展，但玩家线受损，控制对象可能缩小、转移或被迫重建。

## 当前实现状态

当前代码尚未实现统治集团、人物、家族、阶层、合法性、政权压力测试或政权更替。现有 `player.id` 只是基础玩家标识，不代表完整统治集团系统。

## 后续实现建议

- 第一版可以只做抽象统治集团，不急于加入完整人物和家族谱系。
- 政权压力测试应与生产力革命绑定，避免成为每回合重复结算的噪音。
- 压力测试结果应提供策略空间，而不是纯随机惩罚。
- 新权力集团应由实际生产方式产生，例如冶金推动工匠和军官，商业推动商人，工业推动资本家和工人。

- 合法性和控制力是否应按区域分别计算？
